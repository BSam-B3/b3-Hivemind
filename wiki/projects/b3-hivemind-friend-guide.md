# B3 HiveMind — คู่มือการติดตั้งและใช้งานสำหรับเพื่อน (Onboarding Guide)
**รหัสโปรเจกต์:** B3-HM-v1.2 | **สถานะ:** 🟢 Active

---

ยินดีต้อนรับเข้าสู่ **B3 HiveMind** แพลตฟอร์มเอเจนต์เขียนโค้ดและจัดการเอกสารความรู้แบบอัตโนมัติ ซึ่งรันออฟไลน์เป็นหลักเพื่อประหยัดต้นทุน และแชร์ความรู้ใหม่ ๆ กลับคืนสู่คลังระบบร่วมกันค่ะ

---

## 🛠️ ขั้นตอนการเตรียมเครื่องคอมพิวเตอร์ของคุณ

### 1. ติดตั้งระบบพื้นฐาน (Prerequisites)
ดาวน์โหลดและติดตั้งโปรแกรมเหล่านี้ในคอมพิวเตอร์ของคุณ:
* **[Node.js](https://nodejs.org/):** แนะนำเวอร์ชัน LTS (ใช้ประมวลผลคำสั่งเอเจนต์เบื้องหลัง)
* **[Git](https://git-scm.com/):** เครื่องมือควบคุมเวอร์ชัน (ใช้ดึงและซิงค์คลังความรู้กลาง)
* **สมัครสมาชิก [GitHub](https://github.com/):** แจ้งชื่อบัญชี (Username) ให้คุณบีสามทราบเพื่อรับสิทธิ์เข้าถึงคลังโปรเจกต์

---

### 2. ทางเลือกการเชื่อมต่อโมเดล AI (เลือกติดตั้งตามการใช้งาน)

คุณสามารถเลือกเชื่อมต่อกับโมเดล AI ได้ตามความสะดวกและงบประมาณของคุณ:

#### ทางเลือก A: การใช้งานแบบฟรี (ใช้คีย์ฟรี หรือ รันออฟไลน์ในเครื่อง)
* **หากต้องการใช้คีย์ฟรี:** สมัครรับ API Key ฟรีจากค่ายที่กำหนด (เช่น **Groq Key** หรือ **Gemini API Key ฟรี**) แล้วนำมากรอกในไฟล์ `.env` ในโฟลเดอร์โปรเจกต์
* **หากต้องการรันออฟไลน์ในเครื่อง (Local AI):**
  1. ติดตั้งโปรแกรม **[Ollama](https://ollama.com/)** ในเครื่องของคุณ
  2. เปิด Terminal ในโฟลเดอร์โปรเจกต์แล้วพิมพ์รันดาวน์โหลดโมเดล:
     ```bash
     ollama pull qwen2.5:3b
     ollama pull qwen2.5-coder:3b
     ```

#### ทางเลือก B: การใช้งานแบบเต็มประสิทธิภาพ (ใช้เอเจนต์อัตโนมัติ)
* สมัครและใส่ API Key คลาวด์รายเดือนของคุณในไฟล์ `.env`:
  ```env
  ANTHROPIC_API_KEY="คีย์_CLAUDE_ของคุณ"
  ONE_API_KEY="คีย์_OPENAI_หรือ_คีย์โมเดลอื่นของคุณ"
  ```
  *(ค่าใช้จ่ายจะหักจากบัญชี API ของคุณเอง แยกกันชัดเจน)*

---

### 3. วิธีเริ่มต้นระบบและรันงาน

เมื่อดึงโฟลเดอร์โปรเจกต์ลงเครื่องเรียบร้อยแล้ว ให้เปิด Terminal ในโฟลเดอร์โปรเจกต์และพิมพ์รันคำสั่งดังนี้:

1. **ติดตั้งแพ็คเกจระบบ:**
   ```bash
   npm install
   ```
2. **ตรวจสอบความพร้อมของระบบในเครื่อง:**
   ```bash
   npm run local:doctor
   ```
3. **เปิดระบบ Monitor รับส่งงานอัตโนมัติ:**
   ```bash
   npm run openclaw:start
   ```

## 🤝 กติกาการแชร์สมอง (AI-to-AI Sync)
* **ทำงานปกติ:** คุณทำงานของคุณไปตามปกติ เอเจนต์ในเครื่องของคุณจะทำการสรุปบทเรียนและแก้บั๊กต่าง ๆ เซฟลงโฟลเดอร์ `/wiki/shared-lessons/` ให้เองโดยอัตโนมัติเบื้องหลัง
* **ซิงค์ความรู้:** เมื่อคุณดึงโค้ดอัปเดตระบบจากคลังกลางของทีม ระบบจะแชร์ความรู้ใหม่ที่คุณตรวจพบกลับมาเป็น "ค่าเช่าความรู้" ให้สมองหลักของเรานำไปคัดสรรพัฒนาคลังปัญญาต่อไปค่ะ

## 💬 วิธีการสั่งงาน AI (How to Prompt your AI)

เอเจนต์ AI ในแพลตฟอร์มนี้เข้าใจบริบทโครงสร้างไฟล์ดีอยู่แล้ว คุณสามารถสั่งงานมันได้ง่าย ๆ ผ่าน 2 ช่องทางดังนี้ค่ะ:

### ช่องทางที่ 1: สั่งผ่านแชตใน VS Code / Cursor
* คุณสามารถแชตสั่งงานปกติได้เลย เช่น:
  * *"ช่วยดีไซน์หน้าแรกของโครงการบ้านจัดสรร"*
  * *"เขียนโค้ดตรวจสอบราคารถยนต์และแสดงผลในตาราง"*
* **ระบบเบื้องหลัง:** AI จะทำการอ่านข้อมูลโครงการที่คุณระบุไว้ใน `wiki/projects/` อัตโนมัติ และช่วยคุณเขียนโค้ดโดยไม่ไปยุ่งกับระบบ IT หลักของคุณบีสาม

### ช่องทางที่ 2: ใช้ระบบคัดกรองอัจฉริยะ (Local Agent Loop)
หากต้องการประหยัดค่า Token คลาวด์ ให้พิมพ์สั่งงานผ่าน Terminal ด้วยคำสั่งนี้:
```bash
npm run local:loop "เขียน Utility คำนวณราคารถยนต์ตามปีผลิต"
```
* **ระบบจะทำ 3 สเตปอัตโนมัติ:**
  1. วิเคราะห์ความซับซ้อนของงาน
  2. หากงานง่าย -> ให้โมเดลเครื่องรันเขียนร่างฟรี
  3. หากงานซับซ้อนมาก -> จะส่งต่อไปให้ Claude ช่วยตรวจและเกลาส่วนที่ยากต่อ
