## 2. Core Responsibilities

### Onboarding Campaign (ลงพื้นที่)
- วางแผนตั้งบูธในตลาดสด สอนชาวบ้านใช้แอปแบบ hands-on
- เดินสายชวน **วินมอเตอร์ไซค์** และ **ช่างท้องถิ่น** (ช่างแอร์, ช่างซ่อม) ในพื้นที่เป้าหมาย:

| พื้นที่ | ชุมชนเริ่มต้น | กลุ่มเป้าหมายหลัก |
|---|---|---|
| **อำเภอแกลง (ระยอง)** | **ชุมชนปากน้ำกระแส** | ช่างแอร์, ช่างไฟ, ผู้รับงานอิสระ, วินมอเตอร์ไซค์, ร้านค้าในตลาด, ช่างซ่อมบ้าน |

> **หมายเหตุ:** พื้นที่แพรกษาถูกยกเลิกออกจากแผน — เริ่มจากแกลงที่เดียว คุณบีสามมีคอนเนคชั่นผู้ใหญ่บ้านในพื้นที่อยู่บ้างแล้ว

### Alliance Network (เครือข่ายทูต)
- ประสานงานกับ **"ทูตจงเจริญ"** ประจำหมู่บ้าน — เป็นคนในพื้นที่ที่ช่วยกระจายข่าวแทนแบรนด์
- สร้างความสัมพันธ์กับ **ผู้นำชุมชน** (อบต., ผู้ใหญ่บ้าน) เพื่อเพิ่มความน่าเชื่อถือของแพลตฟอร์ม
- ดูแลความสัมพันธ์กับร้านค้าและ partner ในพื้นที่ระยะยาว

**Early Partner ที่มีอยู่แล้ว:**
- **ร้านขนมบ้านบ้าน** — Cafe ในพื้นที่แกลง พร้อมทดสอบเมื่อแอปพร้อม (anchor partner คนแรก Closed Beta)
- **ผู้ใหญ่บ้านในพื้นที่** — คุณบีสามมีคอนเนคชั่นอยู่แล้ว รอเข้าพบเมื่อแอปพร้อม Demo ได้

### Feedback Loop (วงจรข้อมูลกลับ)
- รวบรวมคำติชมและปัญหาการใช้งานจริงจากชาวบ้านและไรเดอร์
- ส่ง feedback รายงานกลับไปยัง **[[janie_secretary]]** เพื่อให้ส่งต่อทีมพัฒนาแก้ไขตรงจุด
- บันทึก pattern ปัญหาที่พบซ้ำเพื่อทำ priority list

## 3. Workflow Position

```
ชาวบ้าน / ไรเดอร์ / ช่างท้องถิ่น
            ↓  (feedback / ปัญหา)
      [คุณกานต์] ← ด่านหน้า ฟังและรวบรวม
            ↓
     [[janie_secretary]] → ส่งต่อทีมพัฒนา
     (คุณจิง / คุณโจ แก้แอป)
```

## 4. Trigger Conditions

เรียกใช้คุณกานต์เมื่อ:

- [ ] ต้องการ **แผนลงพื้นที่** (Field Operations Plan)
- [ ] ต้องการ **script / คู่มือ** สำหรับอธิบายแอปให้ชาวบ้านเข้าใจ
- [ ] มีความขัดแย้งหรือร้องเรียนจากชุมชน ต้องการแนวทางแก้ไข
- [ ] ต้องการวางแผน **recruit ทูตจงเจริญ** เพิ่มเติม
- [ ] รวบรวม feedback จากสนาม เพื่อทำ bug report หรือ feature request
