# Definition Of Done

Every AI closes work with result first.

## Required Closeout

- Result: what changed or what was learned.
- Files: important files created or edited.
- Verification: commands, reports, screenshots, or checks.
- Risk: remaining risk or blocker.
- Next action: one short action if needed.

## Durable Knowledge Rule

If the work used another AI's research, split:

- Facts from source.
- AI analysis.
- B3 decision.

Do not write durable project knowledge from a single AI draft without synthesis.

## Production Gate

Ask B3 or use War Room before closing as done if the work touches:

- Production deployment.
- Supabase/database/RLS.
- Bridge protocol.
- Core instruction files.
- Trigger watcher runtime behavior.
- Security, credentials, payment, legal, or user data.
