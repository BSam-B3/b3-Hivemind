## 🗂️ โครงสร้าง

```
wiki/mini-projects/
├── README.md          ← ไฟล์นี้ (index + rules)
├── _TEMPLATE.md       ← template สำหรับสร้างไฟล์ใหม่
├── [MP-xxx-ชื่อ].md  ← งานที่กำลังทำหรือค้างอยู่
└── done/              ← งานที่เสร็จแล้ว (ย้ายมาที่นี่)
```

## 🚦 Status System

| Badge | ความหมาย | AI ควรทำอะไร |
|:------|:----------|:-------------|
| 🔄 In Progress | กำลังทำอยู่ | อัปเดต log ทุก 10 tool calls หรือ 20 นาที |
| ⏸ Blocked | ติด / รอ B3 หรือข้อมูล | เขียน Next Action ไว้ให้ชัดก่อนหยุด |
| 🔁 Handoff | พร้อมส่งต่อ | AI ตัวอื่นอ่าน Next Action แล้วรับต่อได้เลย |
| ✅ Done | เสร็จแล้ว | ย้ายไป `done/` + บันทึกบทเรียนลง wiki/ |

## 🎯 Priority System (AI ใหม่รับงานตามลำดับนี้)

| Badge | ความหมาย | รับทำ |
|:------|:----------|:------|
| 🔴 Urgent | บล็อก production / B3 รอ | ทันที — ก่อนทุกอย่าง |
| 🟡 Normal | งานทั่วไป ควรทำต่อ | ตามลำดับใน Index |
| 🟢 When Free | ไม่เร่ง | เมื่อไม่มี 🔴🟡 ค้างแล้ว |

## 📏 กฎการใช้งาน

1. **สร้างทันที** — เมื่อเริ่มงานที่ใช้เวลา >15 นาที หรือมีหลาย step
2. **อัปเดตทุก step** — tick checkbox + เพิ่ม log entry
3. **เขียน Next Action ก่อนหยุดเสมอ** — เขียนละเอียดพอให้ AI ใหม่ทำต่อได้ทันที
4. **ห้ามทิ้งไฟล์ค้าง** — ถ้าเสร็จแล้วต้องย้ายไป `done/` ภายใน session เดียวกัน
5. **ID format:** `MP-YYYYMMDD-NNN` เช่น `MP-20260602-001`
